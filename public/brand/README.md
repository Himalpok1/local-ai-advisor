# Local AI Advisor asset set

These brand assets are stored in `public/brand`. The website uses the logo mark, the horizontal logos and the local-stack illustration; the remaining assets are legacy.

## Visual direction

Neobrutalism: cream paper, thick near-black outlines, hard offset shadows (no blur), flat saturated fills.

- Ink `#171410`, cream `#FDF8E7`, yellow `#FFCF1F`, green `#2EE88C`, pink `#FF9BE8`, blue `#6FA8FF`, orange `#FF9F43`, teal `#2A9D8F`.
- No gradients, glows or soft shadows. Outlines are 3-4 px on a 64 px mark, shadows are offset ~4 px.
- The mark is a yellow tile with four progress segments and a green result dot, reflecting the app's fit levels.
- Site colours live in `app/globals.css` (`--ink`, `--primary`, `--sticker-*`, `--f-*`); in-page shapes and illustrations live in `components/art/`.

## Files

| Asset | Intended use |
| --- | --- |
| `logo-mark.svg`, `logo-mark-light.svg` | Compact app/social mark on light or dark contexts |
| `logo-horizontal.svg`, `logo-horizontal-dark.svg` | Header, footer, and media lockups |
| `logo-mark-128.png`, `logo-mark-512.png` | Raster mark exports; also used to make `app/favicon.ico` |
| `icon-{hardware,model,memory,speed,compatibility,comfort}.svg` | Topic and feature icons |
| `illustration-four-tiers.svg` | Capability explanation graphic |
| `illustration-local-stack.svg` | Stack builder explainer graphic |
| `editorial-capability-layers.png/.webp` | Hero or article illustration |
| `editorial-model-choice.png/.webp` | Model selection or social illustration |
| `fit-check.gif`, `fit-check-poster.png` | Short four-step progress loop and reduced-motion still |
| `asset-preview.png` | Contact sheet for review only |

The logos (`logo-*.svg`, `logo-mark-*.png`) and `illustration-local-stack.svg` are generated by `python3 scripts/generate-neobrutal-brand.py --png` (the PNGs need Playwright/Chromium; `app/favicon.ico` is made from `logo-mark-512.png`). The other files (`icon-*.svg`, `illustration-four-tiers.svg`, `editorial-*`, `fit-check.*`, `asset-preview.png`) are the older indigo set from `scripts/generate-brand-assets.py`; the site does not use them and they are due for a refresh if they are ever needed. The editorial images are original generated raster assets.
